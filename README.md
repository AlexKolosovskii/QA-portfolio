## 📂 Структура проектов

### 🧪 1. Тест-дизайн и документация
[📁 Открыть раздел](./01_Manual_Testing_Artifacts/)

Базовые техники тестирования и работа с артефактами.

- **Классы эквивалентности и граничные значения (EP & BVA)** — Анализ формы регистрации, подбор тестовых данных.
- **Попарное тестирование (Pairwise)** — Оптимизация тестов для фильтров и сортировки с помощью PICT/Teremok.
- **Таблица принятия решений (Decision Table)** — Логика оплаты через PayPal, покрытие сложных условий.
- **Чек-листы, Тест-кейсы и Баг-репорты** — Полное функциональное тестирование интернет-магазина: от чек-листа до заведения дефектов в Jira-стиле.

### 🌐 2. API Тестирование (Postman)
[📁 Открыть раздел](./04_WEB_API_Testing/)

Работа с REST и SOAP архитектурами, написание автотестов.

- **REST API: Интернет-магазин DemoShopping** — Коллекция запросов (CRUD), переменные окружения, автотесты статус-кодов и тела ответа.
- **SOAP API: Country Info Service** — Работа с XML, тестирование SOAP-методов, негативные сценарии.

### 💾 3. Базы данных (SQL & NoSQL)
[📁 Открыть раздел](./03_Database/)

Работа с данными, сложные выборки и миграция.

- **SQL запросы (MySQL)** — Подключение к БД, JOIN-запросы, агрегация данных, создание заказов.
- **NoSQL миграция (MongoDB)** — Создание кластера в Atlas, перенос данных из реляционной таблицы в документоориентированную коллекцию.

### 🎨 4. Frontend Практика (HTML/CSS)
[📁 Открыть раздел](./05_HTML_CSS/)

Основы верстки и понимания структуры веб-страниц.

- **Мое первое портфолио** — Верстка личной страницы с нуля, адаптивный дизайн, структура проекта.
